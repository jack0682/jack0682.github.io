## 실험 프로그램의 질문

관측된 latent alignment가 있다는 사실과 별도의 ULR object가 필요하다는 주장은 다르다. 경험 프로그램은
다음 사슬을 닫도록 설계됐다.

$$
\text{phenomenon}
\to
\text{null robustness}
\to
\text{gauge typing}
\to
\text{strong baseline comparison}
\to
\text{held-out behavior}
\to
\text{nonreduction verdict}.
$$

## 1. 최초 경험 원자 6건

| ID | 현재 관측 | 허용되는 해석 | 금지되는 해석 |
|---|---|---|---|
| `ULR-CONV-EXIST` | 제한된 concept/model pair의 relation geometry가 shuffled null 초과 | 해당 pair에 shared alignment 있음 | observer-independent common space |
| `ULR-CONV-INDEP` | independent vision-only × language-only pair도 chance 초과 | 공동 CLIP 학습만의 산물은 아님 | 모든 modality의 공통 ULR |
| `ULR-CONV-DIM` | held-out null 초과가 CIFAR 20/25, Caltech 24/25 축에서 관측 | 단일 축만의 현상은 아님 | exact intrinsic dimension 17·20·24 |
| `ULR-CONV-SEM` | alignment가 semantic/language proxy와 graded association | 선택 proxy와 연관 | 의미와 동일 |
| `ULR-CONV-ORIGIN` | initialization near-chance에서 학습 중 typed trend $\rho=0.881$ | statistic이 학습 중 강화 | exact formation onset |
| `ULR-EMP-GAUGE-ROBUST` | T1/T2 exact, T3 trend가 지정 permutation × positive-diagonal typing에서 보존 | raw-coordinate artifact만은 아님 | 일반 GL·nonlinear·full-model gauge robustness |

이 여섯 행은 **ULR object 발견 6건**이 아니다. 현상과 artifact boundary를 기록한 active claim이다.

## 2. Zero-assumption 재개방에서 확인한 수치

재개방 감사는 이전의 headline을 그대로 재사용하지 않고 source, null, model family를 다시 분리했다.

| 검사 | 결과 | 정본 해석 |
|---|---:|---|
| raw cross-modal CKA | 0.769 | 지정 model pair의 relation statistic |
| shuffled baseline | 0.583 | 같은 protocol의 null |
| standardized gap | $z=35.9$ | 이 pair에서 chance 초과 |
| supervised × supervised, 14-model atlas | 0.803 | objective family 안의 높은 정렬 |
| self-supervised × self-supervised | 0.468 | 보편 수렴과 불일치 |
| untrained × untrained | 0.571 | architecture·data prior가 무시할 수 없는 baseline |
| graded animacy proxy 설명분 | 약 25% | 선택한 proxy family의 설명력 |
| 미설명분 | 약 75% | 18개 proxy가 설명하지 못한 잔차, ULR 크기 아님 |

과거 `≥17`, shared/private `52%`, PC 제거 뒤 `48%`, exact formation onset 같은 provenance 미충족 숫자는
현재 정본의 존재 하중에 쓰지 않는다.

## 3. Gauge-typed replication이 바꾼 결론

raw representation metric은 function-preserving coordinate change에도 움직일 수 있다. T1–T3 replication은
원 좌표의 현상과 typed quotient를 함께 비교했다.

- T1에서 raw effective dimension은 20에서 16으로 변했지만 typed 값은 bit-identical하게 보존됐다.
- T2에서 raw modality-specific score는 0.251에서 0.119로 줄었지만 typed score 0.237은 보존됐다.
- T3는 처음 재현 실패 후 extraction protocol 차이를 추적해 last-token·final-layer·고정 prompt 조건에서
  CKA correlation 0.997, retrieval Pearson 0.986으로 원 추세를 복원했다.

결론은 다음 한 문장으로 동결됐다.

> 현상은 gauge artifact가 아니었지만, raw 측정값은 gauge artifact에 노출되어 있었다.

이는 full-model gauge orbit 전체를 시험했다는 뜻이 아니다. 지정한 permutation과 positive-diagonal
typing의 범위다.

## 4. B0–B4와 combined B*

새 quantity $Q$의 가치는 약한 baseline 하나가 아니라 같은 information·port contract에서 가능한 가장
강한 설명과 비교한다.

| Baseline | 관측 범위 | 제거하려는 오독 |
|---|---|---|
| B0 output | passive output만 | 출력 차이를 새 internal object로 부르는 것 |
| B1 geometry | passive representation geometry | 관계 metric의 중복 정보 |
| B2 predictive | passive future prediction | ordinary predictive state의 흡수 |
| B3 causal testing | raw controlled port response | response quotient의 표준 testing 흡수 |
| B4 routing | architecture가 선언한 state·write routing | 설계 label을 emergent organization으로 오인 |
| B* | B0–B4 결합 | 여러 약한 null을 따로 이긴 결과의 공허한 승격 |

M8을 열려면 $Q$가 B* 이후에도 held-out behavior 또는 transfer에 점증적 가치를 줘야 한다.

## 5. U0-v1 — exact toy를 small neural system으로 옮기기

이 실험은 동일하게 학습된 core를 두 persistence mechanism에 연결했다.

- A: write activation을 recurrent hidden에 보존.
- B: one-item attention cache에 보존하고 query 때 activation을 재구성.
- 32 seed, meta-train 24 / meta-test 8.
- passive write·tick·read에서 activation과 probability가 pairwise exact.
- hidden/cache reset, clone, overwrite가 실제 state container에 작용.

passive probability와 activation 최대차는 0, CKA는 1이었다. reset·clone 방향은 32/32 seed에서
일치했다. signed-permutation co-transform 아래 passive output과 physical response도 수치 오차 범위에서
보존됐다.

### Held-out prediction

| Predictor | test MSE | test $R^2$ |
|---|---:|---:|
| B0 output | 0.9652701411 | 0.0 |
| B1 passive geometry | 0.9652701411 | 0.0 |
| B2 passive predictive | 0.9652701411 | 약 0 |
| B3 raw port response | 0.0000105580 | 0.999989 |
| B4 declared routing | 0.0000014978 | 0.999998 |
| Q typed response | 0.0000007289 | 0.999999 |

$Q$는 B2보다 크게 나았지만, B3·B4 대비 우위는 사전등록한 0.01 nonabsorption threshold에 미달했다.
따라서 operational bridge는 양성이지만 ontology 판정은 `Z1_WEAKENED`다.

## 6. M1 — Z1 physical response의 emergent version

U0-v1이 engineered routing을 사용했으므로 M1은 homogeneous tanh RNN의 seed-only training에서 stable
response class가 자연히 갈리는지 검사했다.

- 64 seed 모두 passive eligibility를 통과.
- stable class는 train 47:1, test 16:0으로 형성되지 않음.
- raw response도 ordinary dynamics baseline을 개선하지 못함.
- local verdict: `COLLAPSED@tanh-delay-v2`.

이 결과는 모든 physical-response 가설을 반증하지 않는다. current implementation의 emergent v2를 닫고
Z1 전체를 weakened application program으로 남긴다.

## 7. M2 — Z5 external relation cross-fit

외부 semantic relation을 고정하고 한 dataset에서 맞춘 relation law가 다른 dataset과 model family로
transport되는지 검사했다.

- 고정한 WordNet 3.1 relation이 Caltech와 CIFAR의 held-out relation을 예측.
- architecture·objective holdout을 통과.
- geometry relation gate는 양성.
- retrieval behavior bridge는 악화되어 음성.

따라서 Z5는 **weakened external baseline**이다. 외부 taxonomy가 representation geometry를 일부
예측한다는 결과는 남지만, internal carrier나 behavior mechanism으로 승격되지 않는다.

## 8. M3 — 일곱 carrier의 동일 reduction audit

| 후보 | 환원 대상 | Neural-specific survivor |
|---|---|---:|
| parameter quotient | symmetry/invariant quotient | 0 |
| activation ensemble | empirical law/kernel/moment | 0 |
| relation transform | RSA/CKA/external relation | 0 |
| predictive state | PSR/minimal realization | 0 |
| physical response | causal testing | 0 |
| dynamical carrier | ordinary state-space/RDS | 0 |
| external relation | internal object가 아님 | 0 |

최종 합계는 **0/7**이다. 이 판정은 현재 registry를 닫지만 미래의 모든 carrier 후보를 금지하지 않는다.

## 9. M4 — Formation의 조건부 정의

formation은 metric curve의 onset이 아니라 identity와 transport 아래 object 또는 family의 structural
type이 바뀌는 사건으로 정의했다.

필수 항목은 다음과 같다.

1. formation 이전과 이후의 object identity;
2. cross-time transport;
3. quotient 안의 단순 이동과 structural stratum change의 구분;
4. behavior를 정의에 넣지 않은 별도 bridge;
5. deformation과 boundary crossing의 구분.

M3 survivor가 0이므로 모든 neural model에 적용할 current target은 `NO_ADMISSIBLE_TARGET`이다. 정의는
완료됐지만 universal instance는 없다.

## 10. M5 — UAR composite 철회

M5는 이전 UAR-I 완성 인상을 재검사했다. 결과적으로 full channel incidence의 injectivity와 joint
assembly quotient의 unramifiedness가 서로 다른 source와 map에 대한 명제임을 확인했다.

따라서 `ULR-ASSEMBLY-UAR-MONO`를 `RETRACTED-MALFORMED-COMPOSITE`로 내렸다. 보존한 것은 다음 두
하위 결과다.

- `ULR-UAR-CH-TYPED-EXCLUSION`;
- `ULR-UAR-ASM-UNRAMIFIED`.

localization identity와 CERT-B/C는 M8을 막지 않는 optional strengthening으로 이동했다.

## 11. M6 — Baseline contract 종료

M6은 모든 후속 candidate가 같은 기준에서 평가되도록 B0–B4와 B*를 고정했다. candidate와 baseline은
같은 split, information access, intervention vocabulary, precision, resource ledger를 공유해야 한다.
baseline이 candidate wrapper를 실행할 수 있는데 그것을 금지하려면 provenance-blind한 별도 doctrine이
필요하다.

## 12. M7 — Hypothesis와 governance 종료

Z0–Z7 각각에 다음을 사전등록하는 계약을 완성했다.

- object와 identity;
- strongest rival;
- rival-specific falsifier;
- independent prediction;
- data·split·hash·amendment rule;
- finite termination;
- raw receipt와 validator;
- author closure와 independent audit의 분리.

8개 가설의 14필드 schema는 형식 검사를 통과했다. 형식 통과는 truth나 novelty를 뜻하지 않는다.

## 13. M8 — 최종 ontology 판정

M8은 앞의 결과를 단순 투표하지 않고 **모든 typed baseline 이후 남은 residual**을 물었다.

| 후보 근거 | 관측 결과 | M8 해석 |
|---|---|---|
| physical response | passive quotient보다 richer | B3/B4 testing·routing이 흡수 |
| emergent persistence | stable class 없음 | Z1 v2 collapsed |
| external relation | geometry cross-fit 양성 | behavior 음성, internal carrier 아님 |
| carrier registry | toolkit은 풍부 | survivor 0/7 |
| formation | object-relative 정의 가능 | universal target 없음 |
| UAR | 두 하위 결과 생존 | composite mono 철회 |

따라서

$$
\boxed{\text{M8 verdict}=\textbf{NO}}
$$

를 채택했다. 이 `NO`는 유한 registry와 선언한 baseline 범위의 결론이다.

## 14. Canon 24의 post-verdict theorem

M8 뒤에도 observer-relative role 문제는 exact하게 닫을 수 있었다. role-conditioned transcript law
$P_L,P_I$의 equal-prior Bayes risk는

$$
R^*=\frac{1-\lVert P_L-P_I\rVert_{\mathrm{TV}}}{2}
$$

이고 adaptive policy, garbling contraction, infinite path-law singularity까지 필요충분 경계가 정리됐다.
이 결과는 새 ontology가 아니라 **limited observer의 identifiability theorem**이므로 M8을 재개하지 않았다.

## 15. 재현과 감사에서 배운 것

- saved-output 계산은 현재 환경에서 13/13 stdout hash가 일치했다.
- U0-v1 validator는 prereg, raw shape, split, gate, verdict와 deterministic replay를 12/12 통과했다.
- observer theorem finite verifier는 분포 pair, garbling, adaptive policy를 포함한 8/8 검사를 통과했다.
- 코드 재현은 input provenance와 external access contract 전체를 대신하지 않는다.
- self-audit가 “결과 결함 아님”으로 판정한 자리를 independent audit가 conclusion-level defect로 뒤집었다.

따라서 현재 실험 규율은 author-side closure, independent audit, LEDGER promotion을 서로 다른 단계로 둔다.

## 프로그램의 최종 경험 결론

강한 alignment와 exact boundary theorem은 있다. 그러나 current data에서 neural-specific ULR object를
추가했을 때 얻는 held-out explanatory value는 없다. 경험 프로그램이 실패한 것이 아니라, **선호한
ontology보다 강한 null을 끝까지 유지해 `NO`를 판정할 수 있게 된 것**이 현재 결과다.
